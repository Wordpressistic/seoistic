# SEOistic 1.6.5

## Purpose

This maintenance release makes sitemap output consistent across SEOistic’s
native XML integration and its HTML sitemap shortcode. It is safe for existing
sites and does not change the database schema.

## Changes

- HTML sitemap output now includes all published, publicly viewable post types
  instead of stopping at 300 items.
- URLs are deduplicated across post types.
- SEOistic noindex metadata is honored in both current (`_seoistic_noindex`)
  and legacy (`_seoistic_robots`) forms, including directives such as
  `noindex,nofollow`.
- Existing sitemap query filters are preserved while the indexability boundary
  is added.
- A Windows PowerShell release builder is included for deterministic packaging
  on hosts without `rsync`.

## Verification

- PHP syntax checks passed for all changed runtime files.
- All 32 license entitlement regression checks passed.
- The runtime ZIP was verified to contain only the `seoistic/` package root.

## Deployment

Install `seoistic-1.6.5.zip` through WordPress plugin update/install flow. The
plugin remains GPL-2.0-or-later. Premium features still require a valid
WPistic entitlement; this release does not bypass licensing or provider
authentication.
