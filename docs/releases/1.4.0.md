# SEOistic 1.4.0

## Highlights

- WPistic licensing integration
- Protected updates via WPistic package authorization
- Entitlement compatibility layer
- Deterministic release packaging script

## Upgrade Notes

Existing installations will keep legacy license options in the database. Administrators should re-activate via the WPistic dashboard or use the License screen to activate with a WPistic-issued key. The plugin will not delete legacy options until migration completes successfully.

## Compatibility

Tested PHP: 8.1 - 8.4
Tested WordPress: 6.4
